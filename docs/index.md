# DeepSeek Automation API

Документация по проекту **DeepSeek Automation API** — локальному прокси-серверу,
который эмулирует OpenAI API, автоматизируя веб-интерфейс DeepSeek
через Playwright.

## Что здесь есть

Проект развивается на двух уровнях одновременно:

- **Код** — реализация в `src/`, `server-modules/`.
- **Алгоритмы** — контрактные описания того, **как** этот код работает.

Раздел «Алгоритмы» — ключевой. Каждый алгоритм зафиксирован один раз и
не подлежит пересмотру без явного решения. Если требуется замена — старый
алгоритм помечается как `deprecated`, новый описывается как отдельная
версия с указанием причины замены.

## Быстрый старт

```bash
git clone <repo>
cd deepseek-automation-api
npm install
npm run build
PLAYWRIGHT_BROWSERS_PATH=./browsers npx playwright install chromium
npm start
```

Подробнее — в разделе [Установка](guides/installation.md).

## Формат описания алгоритмов

Каждый алгоритм в разделе «Алгоритмы» описывается по шаблону:

- **Статус** (`active` / `deprecated`) и **дата фиксации**.
- **Назначение** — что решает.
- **Входные и выходные данные.**
- **Псевдокод** — шаги без привязки к конкретным функциям.
- **Граничные случаи** — ошибки, таймауты, пустые данные.
- **Почему именно так** — причинно-следственная связь.
- **Реализация** — ссылки на файлы (не контракт, может меняться).
- **История версий** — если алгоритм был переработан.

См. [пример — R4 Ранжирование RAG](algorithms/rag.md#r4).
