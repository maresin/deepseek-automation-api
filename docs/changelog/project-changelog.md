# Журнал изменений проекта

## 2026-09-18 — финальная версия для документации

### Изменения в коде

- **Унификация ошибок.** `NeedTransitionError` удалён.
  `ContextExhaustedError` покрывает оба сценария (баннер и программный).
- **Формула ранжирования RAG.** Замена аддитивной на мультипликативную.
- **Разделение порогов снапшота.** 70% — создание, 90% — перезапись.
- **Извлечение ответа.** Копирование через Regenerate-контекст,
  markdown-fallback через `data-virtual-list-item-key`.
- **Ожидание ответа.** Двухфазная стратегия, прокрутка вниз.
- **Разделение состояния.** `state.json` / `chat_state.json`.
- **Server Busy.** Детект через Retry-иконку и точный текст,
  обработка → HTTP 503 → shutdown.
- **Валидация селекторов.** `selector-validator.js` на старте.
- **Фоновая индексация.** `IndexingQueue` для больших файлов.

### Документация

- Создан раздел **алгоритмов** (`docs/algorithms/`).
- Каталог алгоритмов: A1–A6, B1–B7, C1–C7, R1–R8, F1–F4, Q1–Q5, E1–E4.
- Создан раздел **архитектуры** (`docs/architecture/`).
- Создан каталог **селекторов** в машинночитаемом формате
  (`catalog.json`).
- Переработан **mkdocs.yml** с расширенной навигацией.

## 2026-09-15 — RAG-ранжирование v1

### Изменения в коде

- Введено ранжирование по cosine similarity без учёта свежести.
- `LinearIndex` сохранён как единственный индекс.

### Проблемы

- Свежие ответы проигрывали старым с той же семантикой.
- Исправлено 2026-09-18.

## 2026-09-10 — RAG-инъекция через файл

### Изменения в коде

- RAG-контекст передаётся как файл, а не текст в промпте.
- Добавлен `prompts/rag_upload_prompt.txt`.

### Причины

- Модель не доверяла фрагментам в `userText`.

## 2026-09-05 — фоновая индексация

### Изменения в коде

- Введён `IndexingQueue`.
- Файлы индексируются после ответа, не блокируя клиента.

### Причины

- Клиенты таймаутили на больших файлах.

## 2026-08-30 — Server Busy → shutdown

### Изменения в коде

- `detectServerBusy` через Retry-иконку.
- `ServerBusyError` → HTTP 503 → `process.exit(1)`.

### Причины

- После Server Busy DeepSeek не отвечает часами. Ретраи бесполезны.

## 2026-08-25 — двухсостоянийный state

### Изменения в коде

- Разделение `state.json` (cookies) и `chat_state.json` (chat).

### Причины

- `validateEnvironment` перезаписывал `state.json` при старте.

## 2026-08-20 — селектор-валидатор

### Изменения в коде

- `server-modules/selector-validator.js`.
- Проверка критичных селекторов на старте.
- `ensureEnglishLanguage` при инициализации.

### Причины

- Сервер стартовал с устаревшими селекторами и падал при первом запросе.

## 2026-08-15 — двуязычный анализ

### Изменения в коде

- `ContextManager.analyzeUserMessage` + `getLanguageCoefficient`.
- Динамический лимит контекста.

### Причины

- Фиксированный лимит давал неверную оценку для разных языков.

## 2026-08-10 — двухфазное ожидание ответа

### Изменения в коде

- Фаза A (короткие ответы) + фаза B (Stop → done).
- Прокрутка вниз перед проверкой футера.

### Причины

- Короткие ответы проскакивали между опросами Stop.
- Длинные ответы не рендерились полностью.

## 2026-08-01 — извлечение через Copy

### Изменения в коде

- Поиск Copy-кнопки через Regenerate в предках.
- Fallback через markdown.

### Причины

- Копирование из блока кода вместо ответа.
