# Веб-приложение DeepSeek: обзор

DeepSeek Web — это SPA с двумя зонами: **сайдбар** (слева) и
**рабочая область** (справа). Проект автоматизирует вторую, но
использует первую для навигации.

## Структура страницы

```
┌──────────────────┬─────────────────────────────────────────┐
│ Сайдбар          │  Рабочая область                        │
│                  │                                         │
│  [New chat]      │  [лента сообщений]                      │
│  ─────────────   │                                         │
│  Чат 1           │                                         │
│  Чат 2           │  ┌──────────────────────────────────┐   │
│  Чат 3           │  │ [textarea: Message DeepSeek]     │   │
│  ...             │  │ [📎] [DeepThink] [Search] [→]    │   │
│                  │  └──────────────────────────────────┘   │
│  [Профиль ▾]     │                                         │
└──────────────────┴─────────────────────────────────────────┘
```

## Ключевые элементы

| Элемент | Где | Особенность |
|---|---|---|
| New chat | Сайдбар | Работает по-разному в свёрнутом/развёрнутом виде |
| DeepThink / Search | Внутри textarea | Тогглы; Search исчезает в Expert |
| Textarea | Внизу | Единое поле ввода |
| Скрепка | Слева от Send | Открывает dropdown, не нативный диалог |
| Send / Stop | Справа | Меняются в зависимости от состояния |
| Continue | В футере сообщения | Появляется при паузе длинного ответа |
| Copy | В футере сообщения | Появляется при наведении |

## Динамические состояния

UI DeepSeek переключается между несколькими состояниями:

- **Initial:** Send выключен, тогглы доступны.
- **Typing:** Send активен, видны тогглы.
- **Generating:** Send превращается в Stop.
- **Paused (long):** появляется Continue в футере.
- **Server busy:** плашка вместо ответа, Retry-иконка.
- **Length limit:** баннер о достижении лимита.

Все эти состояния детектируются в `ResponseExtractor` и
`ChatController`. Подробности — в [dynamic-states](dynamic-states.md).

## Что автоматизируется

- Вход (через `/sign_in` или cookies).
- Смена языка интерфейса на английский.
- Отправка сообщения с вложениями.
- Ожидание ответа (Stop → Continue → Copy).
- Переход в новый чат при переполнении.
- Восстановление чата по ID.
- Переключение DeepThink / Web Search.
- Загрузка файлов.

## Что не автоматизируется

- Удаление чатов.
- Переименование / Pin / Share.
- Настройки профиля (кроме языка).
- Privacy policy / Terms.

Эти элементы доступны через селекторы (см. каталог), но не вызываются
из API.

## Стабильность селекторов

DeepSeek использует **хэшированные CSS-классы** (`_9f2341b`, `c03d486a`),
которые меняются при каждой пересборке фронтенда. Поэтому селекторы
строятся по приоритету:

1. `data-*` атрибуты (`[data-virtual-list-item-key]`).
2. ARIA (`[role="button"]`, `[role="radio"]`).
3. Дизайн-системные классы (`.ds-toggle-button`).
4. Текст (английский, стабилен при фиксированном языке).
5. SVG-пути иконок (`svg path[d^="M8.3125 0.98"]`).

См. [selectors/principles](../selectors/principles.md).
