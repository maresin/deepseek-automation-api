# Быстрый старт

Этот документ разделён на два:

- **[Установка](installation.md)** — требования, шаги, `.env`, проверка работы.
- **[Использование](usage.md)** — примеры запросов, сценарии, интеграция с SDK.

## Документация

Вся документация лежит в `docs/` и собирается через MkDocs:

```bash
pip install mkdocs
mkdocs serve -f docs/mkdocs.yml
```

Открыть `http://127.0.0.1:8000`.

См. также [алгоритмы](../algorithms/index.md) — контрактные описания
всех процессов API.
