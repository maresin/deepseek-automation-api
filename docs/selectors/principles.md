# Принципы выбора селекторов

Селекторы — самая хрупкая часть автоматизации. DeepSeek использует
CSS-модули с хэшированными именами классов (`_9f2341b`, `_18572c1`),
которые меняются при каждой пересборке фронтенда.

## Приоритеты

| Приоритет | Тип | Пример | Почему |
|---|---|---|---|
| **1** | `data-*` атрибуты | `[data-virtual-list-item-key]` | Добавлены разработчиками для аналитики, стабильны |
| **2** | `role` + состояние | `[role="button"]` | Стандарт доступности (A11y), не зависит от CSS |
| **3** | Дизайн-системные классы | `.ds-toggle-button` | Часть публичной дизайн-системы, меняются редко |
| **4** | Текст (английский) | `:has-text("Continue")` | Стабилен при фиксированном языке |
| **5** | SVG-пути иконок | `svg path[d^="M8.3125 0.98"]` | Уникальны для иконок, редко меняются |

## Что НЕ используется

- **Хэшированные классы** (`._9f2341b`). Меняются при каждой сборке.
- **`:nth-child`/`:nth-of-type`.** Ломаются при добавлении служебных элементов.
- **Полные SVG-пути.** Используем только префикс (`d^="..."`), потому что
  хвост может содержать координаты, меняющиеся при ресайзе.

## Особые случаи

### Страница входа

Интерфейс может быть на любом языке. Селекторы **не должны содержать
английский текст**:

```typescript
emailInput: 'input.ds-input__input[placeholder*="email"]',
passwordInput: 'input.ds-input__input[placeholder*="Password"]',
loginButton: '.ds-button--primary.ds-button--filled:has-text("Log in")',
loginButtonFallback: '.ds-button--primary.ds-button--filled',
```

`loginButton` использует текст, но есть `loginButtonFallback` без текста —
используется, если интерфейс не на английском.

### New Chat

В развёрнутом сайдбаре — `div` без `role="button"`. В свёрнутом —
иконка. Универсальный подход:

```typescript
// Playwright метод, а не CSS-селектор:
page.getByText('New chat').isVisible()
// Fallback:
'[role="button"]:has(svg path[d^="M8 0.599609"])'
```

### Открытие профиля

Иконка «три точки» находится внутри `[tabindex="0"]`, но сам контейнер
не имеет стабильного селектора. Используется `page.evaluate`:

```javascript
const icons = document.querySelectorAll('.ds-icon');
for (const icon of icons) {
  const svg = icon.querySelector('svg');
  if (svg && svg.innerHTML.includes('M4.55146 8.00001')) {
    icon.closest('[tabindex="0"]')?.click();
    return;
  }
}
```

### Извлечение ответа через Copy

Кнопка Copy есть и в футере сообщения, и внутри блоков кода.
Отличительный признак футера — кнопка Regenerate в том же родителе.
Обход предков ограничен глубиной 3:

```typescript
// Найти Copy-кнопку, у которой в предках (≤3 уровней) есть Regenerate.
// Только такая Copy принадлежит футеру ответа, а не блоку кода.
```

## Как обновлять

1. Запустить `npm run test:selectors` — получить отчёт.
2. Для упавших селекторов:
   - Открыть DeepSeek в инспекторе.
   - Найти новый устойчивый признак (data → role → класс → текст → SVG).
   - Обновить `src/browser/Selectors.ts`.
   - Обновить `docs/selectors/catalog.md` и `catalog.json`.
3. Повторно запустить тест.

## Когда селектор ломается

Признаки: API возвращает 500, в логах — «Critical selector not found».
Сервер **не запустится**, если критичный селектор отсутствует —
`selector-validator` проверяет их на старте.

См. [каталог](catalog.md) и [webapp/ui-html-raw](../webapp/ui-html-raw.md).
